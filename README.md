# intro-profession

Практическая работа «Репозитории и интеграции».

## Проект

`rest_api_demo.ipynb` — учебный пример REST API на Python: программа отправляет запрос к [OMDb API](https://www.omdbapi.com/), получает ответ в JSON и выводит сведения о фильме.

## Запуск

1. Создайте виртуальное окружение: `python -m venv .venv`.
2. Активируйте его.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Откройте `rest_api_demo.ipynb` в Jupyter или VS Code.
5. Получите API-ключ на сайте OMDb и введите его при запросе ноутбука.

Ключ вводится во время выполнения и не хранится в исходном коде. `.env` и `.venv/` исключены через `.gitignore`.

## Ветки

- `master` — базовая версия проекта.
- `movie-output-feature` — улучшение вывода информации о фильме.
- `env-feature` — отдельный эксперимент с хранением ключа в `.env`; ветка намеренно не объединяется с `master`.
