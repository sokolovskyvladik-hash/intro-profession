# Рефлексия по практическому занятию № 2

**Репозиторий:** https://github.com/sokolovskyvladik-hash/intro-profession

Работа через API позволяет автоматически обрабатывать заявки, в отличие от ручного общения с моделью в чате. Цепочка LangChain объединяет шаблон промпта, GigaChat-2 и парсер ответа. Системное сообщение задаёт правила, а пользовательское передаёт текст заявки. На 15 заявках базовый промпт дал 11 правильных ответов (73,3%). Например, модель ошибочно включила двух собак в количество проживающих, а в другой заявке вернула правильное число в виде предложения вместо требуемого числа. Few-shot с примерами повысил точность до 80% (12 из 15). Для извлечения дополнительных параметров подготовлена ручная разметка и использован JSON. Первая версия структурированного извлечения показала 10,7%, поскольку 13 ответов не прошли парсер. После добавления примера JSON, уточнения формата даты и повторных запросов средняя точность пяти полей составила 72%: взрослые — 60%, дети — 86,7%, дата — 73,3%, ночи — 60%, цена — 80%. Валидный JSON получен для 13 из 15 заявок, две ошибки декодирования остались. Для учебного запуска пришлось временно отключить проверку SSL, что снижает безопасность соединения. В дальнейшем следует настроить доверенный сертификат и улучшить устойчивость структурированного вывода.
